# 全台保險商品與條款資料取得計畫及申請函稿

**狀態：草稿，尚未寄出。** 這份文件供 Baobab 專案負責人審閱與修改；不代表保險事業發展中心或任何保險公司已授權，也不代表 App 已取得完整商品資料。

## 三條資料取得路線

### 1. 向保發中心申請可用批次資料及使用條件

保發中心公開的商品查詢頁提供公司、險種、商品名稱、銷售日期及停售日期等逐筆查詢條件。頁面亦有圖形驗證與分頁。此次查閱未找到公開批次匯出或 API，也未在該頁確認商用再發布授權。因此第一步應由專案負責人向保發中心詢問官方批次檔、正式 API 或機構合作方式，以及商品資料與附件條款的權利範圍。

官方頁面列出的聯絡信箱為 `adm@tii.org.tw`，電話為 `(02) 2397-2227`。本函尚未寄出。

### 2. 向每一家保險公司索取現售及停售商品資料

官方商品資料庫並不保證每筆商品或每版條款都齊全。應依現行公司及查詢頁歷史公司代碼清單，逐家確認法定公司名稱、公司代碼、現行或歷史狀態、合併承受公司與可提供的檔案。請求範圍應涵蓋 1995 年至今的現售及停售商品、主約與附約、歷次條款版本、銷售/停售日、手術表、給付表、批註及修訂文件。對已併購或停業公司，應向法定承受公司或檔案保管單位索取。

### 3. 補查 2004 年以前的歷史商品與條款

保發中心說明商品資料庫於民國 93 年底（2004 年底）開始建置；更早的商品不能假定已收錄。這段資料需要另向原保險公司、承受公司、檔案保存機關或保戶本人提供的簽發保單逐項確認。找不到的項目應留成「資料缺漏／待補」，不可依商品名稱或後來版本推測條款內容。

## 收到資料後的匯入與驗收欄位

每一商品至少須有以下資料，才可進入商品目錄：

- 官方公司代碼與法定名稱；歷史公司另記承受/更名關係。
- 商品識別碼、商品名稱、主約/附約、險種分類、現售/停售/未確認狀態。
- 銷售起日、停售日、條款版次、生效日及商品適用期間。
- 條款/批註/給付表原始檔或官方穩定連結，文件雜湊值及取得日期。
- 原始來源網址、發布者、來源發布日期、資料取得時間及允許使用的授權證據網址。
- 給付條件與除外責任須能逐條連回條款條號/頁碼；未核對者只能標記待審，不得參與理賠估算。

把授權資料放入 `Resources/product_catalog.json` 後，先執行：

```sh
python3 scripts/validate_product_catalog.py
```

此檢查器只驗證資料格式與必要來源欄位，不代替保險公司核實、法務授權審查或資料完整度稽核。商品目錄中的空缺、無法取得及權利未確認情況需保留狀態，不可靜默略過。
